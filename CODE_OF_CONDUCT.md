# Code of Conduct

## Our standard

This is a bench space. People disagree here for a living — a refuted claim is the goal, not an insult.

Participants are expected to:

- Attack the artifact, not the author. "This check passes on a zero-byte file" is a finding.
  "You are careless" is not.
- State the counterexample, not the verdict. If something is wrong, show the run.
- Accept refutation without tribute. If someone kills your check with one counterexample, that
  person did you a favour.
- Keep language technical. No superiority claims about people, teams, regions, or languages.

The following are not acceptable here: harassment, personal or demographic attacks, sexualised
content or attention, deliberate intimidation, publishing someone's private information, sustained
disruption of discussion, and bad-faith pattern of filing the same refuted claim repeatedly without
new evidence.

## Scope

This applies to issues, pull requests, discussions, commit messages, and any space where someone is
representing this project.

## Enforcement

Report concerns to the maintainers through the contact in `SECURITY.md` (private channel) or by
opening an issue if the matter is public and non-sensitive. Maintainers will:

1. State which behaviour was a problem, quoting it.
2. Apply the least action that stops it: a clarifying reply, an edit request, a locked thread,
   a temporary block, a permanent block.
3. Record the decision in the thread unless doing so would expose the reporter.

There is no separate tribunal and no appeal to a standards body: this project has no standards body.
Decisions are made by the maintainers and written down where they happen.
