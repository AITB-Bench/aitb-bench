# 方法可复用包：把"表格里打勾"换成"可复算的判定"

这个目录是整套方法里**唯一可以离开本包独立使用**的部分。它不含任何业务结论，只有一个核对器、一份规格、一份说明。任何人在自己的协议或法规文本上都能跑。

## 三个文件

| 文件 | 作用 |
|---|---|
| `crosswalk_anchor_check.py` | 通用核对器：读规格 → 回原文查 → 全过退出 0，有失败退出 1 |
| `spec.example.json` | 规格示例（本包 14 条断言的完整写法，可直接跑） |
| `README.md` | 本说明 |

零依赖、纯标准库、单文件。

## 立刻跑起来

```powershell
cd 14_方法可复用包
python crosswalk_anchor_check.py spec.example.json
```

预期：`结果：25/25 通过`，退出 0。

## 它到底在查什么

每条检查三件事：

1. **must**：判定所依赖的原文片段必须真的出现在指定段落。防编造字段名、编造公式、编造措辞。
2. **must_not**：声明"格式里没有某东西"时，该词必须真的不出现。防把"我没找到"写成"它不存在"。
3. **start / end**：可选的两个正则，把查询限定在某一节。防用别节的文字给本节作证。

## 换一个对象要改什么

只改 `spec.example.json`，一行代码都不用碰：

```json
{"id": "X1", "claim": "这条断言在说什么",
 "source": "../路径/某协议正文.txt",
 "start": "3\\.2\\.", "end": "3\\.3\\.",
 "must": ["必须出现的原文片段"],
 "must_not": ["必须不出现的词"]}
```

四条经验，都是踩出来的：

- **片段要够长**。写 `"tier"` 会被无数无关句子命中；写到一句话的完整片段才判得准。
- **数字写法要核**。HIPAA 原文用的是 `6 years` 而不是 `six years`，按后者搜会误判成"原文没有这条"。
- **别把两节的句子混进一条断言**。我们的第一版就犯了这个错：把 §2.1 的字段定义和 §1.4 的术语定义混成一条，结果在 §1.4 里查 §2.1 的句子，直接 FAIL。**那次 FAIL 是对的，是断言写错了。**
- **HTML 抓下来先抽文**。JS 渲染的页面（如 ecfr.gov）直接抓 HTML 是空的，得走 API 或先落盘正文。

## 它不能做什么

- 只证明"我引的那句话在原文里"，**不证明由该句推得出这个判定**。
- 反向检查是词面检查，同义词（`expiry`、`ttl`、`purge`）不会触发；要更严就得给同义词表。
- 不替代外人实测：机器能查锚点，查不了"另一个独立的人能不能复现判断"。

## 与评分器的分工

| 工具 | 回答的问题 | 失败意味着 |
|---|---|---|
| `crosswalk_anchor_check.py`（本包） | 我引的话是真的吗 | 判定不得对外 |
| `08_外人复跑包/复跑评分.py` | 别人独立做出来跟我一样吗 | 方法不可复现 |
| `bench.py` / `assay.py` 的 preset | 这一线整体还能不能交付 | 不能发 |

三者缺一，"可复跑"就是形容词。
